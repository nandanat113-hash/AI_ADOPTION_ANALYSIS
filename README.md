# AI Adoption Analysis | Power BI

## Project Overview
This project focuses on analyzing AI adoption across different industries, countries, company sizes, and AI tools using Microsoft Power BI.

The dashboard provides insights into AI adoption rates, user activity, and the popularity of different AI tools to understand how organizations and individuals are adopting artificial intelligence.

## Objectives
- Analyze AI adoption rates across different countries.
- Identify the most popular AI tools.
- Compare AI adoption across industries.
- Analyze daily active users of different AI tools.
- Understand adoption patterns across user segments.
- Generate meaningful business insights through interactive dashboards.

## Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX (Data Analysis Expressions)

## Project Pages

### 1. Overview
Provides a summary of AI adoption with key performance indicators and country-wise adoption analysis.

### 2. AI Tool Performance
Analyzes AI tool adoption across industries, daily active users, and tool performance.

### 3. User & Industry Analysis
Explores AI adoption patterns across different industries and user segments.

### 4. Insights
Highlights important findings and business insights derived from the analysis.
